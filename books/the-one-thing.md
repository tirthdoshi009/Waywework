# The ONE Thing

Gary Keller and Jay Papasan, 2013. I read it because a day can fill with
requests that all appear urgent while the question that would change the work
remains unanswered.

## What the Book Argues

The book argues that extraordinary results come from deliberately narrowing
attention to the one action that makes the rest easier or unnecessary. The
authors call this a domino effect: completing the right small action creates
the conditions for the next one.

They use a focusing question: what is the one thing I can do such that, by
doing it, everything else will be easier or unnecessary? The question applies
at different scales, from a long-term purpose to the next work block. Its
purpose is not to find the only work that matters. It is to find the work that
must happen first.

The book rejects multitasking as a route to meaningful progress. Treating every
request as equally important turns priority into a long list. Focus means
working in sequence, protecting time for the highest-leverage task, and
accepting that some useful work must wait.

## What I Will Use

**Choose the lead domino.** Before starting a busy day, identify the question,
decision, or change that would remove the most uncertainty for everyone else.
Do that before work that merely makes the queue look shorter.

**Work backwards from the outcome.** Name the result I want, then the next
smaller result that enables it, until there is an action I can complete now.
This keeps a large goal from becoming a reason to make a vague plan.

**Protect the first block.** Put the one action in the calendar with a clear
definition of done. Put messages and other reactive work around that block,
not inside it. A block without a question is only protected browsing.

**Treat trade-offs as deliberate.** Say which work is deferred, delegated, or
declined while the priority is underway. Focus is not pretending that the
other work disappeared; it is making the cost visible early.

## Where It Needs Restraint

One task cannot answer every need in a working day. Incidents, colleagues who
hold needed context, and commitments with a promised response time can all
rightly interrupt a plan. The useful test is not whether I protected the block
at all costs, but whether the interruption was more consequential than the
work it replaced.

The book treats temporary disorder as a necessary cost of focus. That is useful
when I am choosing between two pieces of my own work. It is not permission to
leave a dependency uncommunicated or make someone else absorb the disorder.

## What It Changes

Use the focusing question after writing [Known, Unknown, Not needed,
Next](../docs/communication.md). The Unknown that, once resolved, would make
the most other steps easier is usually the lead domino. If no unknown has that
effect, the work is already small enough to start.

Before accepting more work, name the current lead domino and its planned end.
If the request cannot wait, say which existing priority it replaces. That makes
the trade-off a decision rather than a private interruption.

## Review Questions

- What is the one action that would make the most other work easier?
- Is its definition of done observable before I begin?
- What work am I deliberately delaying while I do it?
- Did an interruption carry more consequence than the work it replaced?
