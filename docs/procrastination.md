# Procrastination

Procrastination is not starting a task that matters, without having decided
against it and without anything more urgent taking its place. The work gets
imagined as one large, hard block, and the imagining is enough to keep it
untouched.

The imagined version is almost always heavier than the real one. What gets
avoided is rarely the work itself; it is the picture of the work built before
touching it.

## Separate Delay from Restraint

This handbook argues for pausing. [Working with
Restraint](working-with-restraint.md) covers the pause before an action, and
[Pace](pace.md) covers not overriding a system's built-in speed. Procrastination
borrows the language of both and is not the same thing.

The difference is whether the delay is waiting on something nameable. Restraint
waits on a specific input: a review, a bake period, a person who returns on
Monday. Procrastination waits on nothing in particular.

Ask what would have to arrive for the work to begin. If the answer is a named
thing with a date, the delay is deliberate. If there is no answer, or the answer
is a feeling of being ready, the delay is avoidance wearing better clothes.

## Resistance Usually Means the Next Step Is Unnamed

A task that feels hard is often a task whose first action was never written
down. The weight is not the difficulty; it is holding an undefined thing in mind
and re-deciding what it is every time it surfaces.

[Four Stages of a Task](four-stages-of-a-task.md) already gives the test: if the
Next line cannot be written, the work has not been made small enough to start.
Do not treat that as a reason to read more. Treat it as the actual first task:
naming the step is the work that is being avoided.

## Start Small, and Let the Start Be Short

Sit with the thing for five minutes. Not to finish it, and not with a promise to
continue; five minutes is the whole commitment.

This works because the resistance lives at the boundary, not inside the work.
Once the file is open and the first line exists, continuing costs far less than
beginning did. Most five-minute starts run longer on their own, and the ones
that do not still leave the task in a smaller, more legible state than before.

Do not raise the number because it worked once. The point of five minutes is
that it is too small to argue with. An hour is negotiable, so it gets
negotiated.

## Make the Five Minutes Produce Something

A short start can quietly become browsing, which feels like diligence and moves
nothing. Guard against that by requiring an artifact: a written question, a
failing test, a draft paragraph, a message half-composed.

Prefer the smallest step that produces something someone else could correct.
That converts a private struggle into a visible object, and a visible object is
much harder to avoid than an intention.

## Recognise Productive Avoidance

The clearest sign of procrastination is not an empty day. It is a full one in
which the important item never moved.

Reading around the problem, reorganising notes, clearing easy mail, and picking
up small well-defined tasks all supply the feeling of work without approaching
the thing being avoided. These are worth doing at some point; they are not worth
doing instead.

At the end of a busy day, name what moved. If the answer is only adjacent items,
the day was avoidance with good posture.

## The Dread Is Often Social, Not Technical

The delayed item is frequently a message rather than a piece of work: a question
that reveals something was not understood, a correction, an estimate that will
disappoint, an admission that an earlier approach was wrong.

Name that honestly rather than restating it as a scheduling problem. Waiting
does not make the message easier to send, and it usually makes it worse, because
the delay itself becomes part of what has to be explained. [Saying I Do Not
Know](saying-i-dont-know.md) covers the admission; the only thing to add here is
that it gets more expensive the longer it is held.

## Delay You Own and Delay You Impose

Postponing your own work costs you time. Postponing a reply, a review, or a
decision costs someone else theirs, and they usually cannot see why they are
waiting.

Treat those as different classes. Anything another person is blocked on is not
eligible for a five-minute start: it gets answered, even partially, even with
"I have not looked at this yet; I will by Thursday." A stated default is
[cheaper for everyone](four-stages-of-a-task.md) than silence.

## A Practical Way Through

When something has been sitting untouched for days, work through this in order
and stop as soon as the task starts moving:

1. Say out loud what is actually being avoided. Not the project, but the
   specific next action inside it. "The migration" is a project. "Ask whether
   we still support the old field" is a task.
2. Check whether it is a genuine wait. Name what has to arrive and when. If
   nothing can be named, continue.
3. Write the smallest step that yields a correctable artifact. If the smallest
   step still feels heavy, it is not the smallest step yet.
4. Set five minutes and start there. No preparation, no tidying first, no
   opening of adjacent documents.
5. Stop when the timer ends if the work has not taken over. Ending on time is
   what makes the next start cheap.
6. Leave the work mid-sentence. A visibly unfinished line is the easiest
   possible re-entry point; a clean stopping place has to be re-approached from
   the boundary again.
7. Write down the Next line before closing. Tomorrow's resistance is largely
   built out of today's undefined ending.
8. If two attempts fail the same way, the problem is not motivation. Something
   is unresolved: an unasked question, a decision that is not yours, a task
   that should not be done at all. Escalate it or drop it rather than
   rescheduling it a third time.

Do not run this list for everything. Use it when something has stopped moving
and the reason is not obvious.

## Review Questions

- What am I actually avoiding, stated as a single action rather than a project?
- What would have to arrive for me to start, and does it have a date?
- Is anyone else blocked on this without knowing why?
- Did the important thing move today, or only the things around it?
- Is the first step small enough that refusing it would feel silly?
- Have I rescheduled this before, and did the reason change?
